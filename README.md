## About This Module

Welcome to the **Managing and Visualising Data** course repository! This collection of hands-on tutorials is designed to complement your learning journey through the principles, challenges, and opportunities around data. <a href="https://moodle.lse.ac.uk/course/view.php?id=17025" target="_blank" rel="noopener noreferrer">Click here for the official Moodle Page</a>.

### Module Overview

Understanding methods for storing, structuring, managing, and visualising data is a core element of any data science foundation, and this course covers these fundamentals. It will complement the coverage of programming and statistical methods in other courses and integrate well with courses that involve importing, manipulating, storing, and retrieving structured and semi-structured data. The coverage of visualisation will raise awareness of how graphics can tap into the human brain's visual processing for a rich understanding of data, and how principles of visual perception can guide methods of visualising data.
